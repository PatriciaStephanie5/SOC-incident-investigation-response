# Lessons Learned

| Priority | Recommendation | Risk addressed |
|---|---|---|
| High | Enforce MFA and conditional access | Stolen credential reuse |
| High | Review permissions and least privilege | Excessive access and blast radius |
| High | Strengthen email filtering and attachment analysis | Phishing and malicious attachments |
| High | Deploy endpoint protection and application control | Malware execution |
| High | Segment critical systems and sensitive repositories | Spread and cross-department access |
| Medium | Improve centralised logging and alert correlation | Detection gaps |
| Medium | Test immutable/offline backups and recovery playbooks | Ransomware availability impact |
| Medium | Run role-based awareness training | Human-factor exposure |

Measure MFA coverage, access-review completion, endpoint detection coverage, phishing-reporting rates, mean time to detect/contain and backup-restore success.
